# v1 Lint 规则

`scripts/lint_report.py` 做非阻断的可读性检查；`--strict` 时把 warning 转为失败。结构、白名单和安全规则由 `validate_report.py` 强制执行。

| ID | 检查 |
| --- | --- |
| L1 | 热力图第二维按行汇总值不单调 |
| L2 | 图表没有 tooltip（表格除外；已声明 measureTypes 时运行时会自动补齐） |
| L3 | 图例字号低于 11 或缺少字号 |
| L4 | 坐标轴字号低于 10 |
| L5 | 图表区块没有可见 `.block-title` |
| L6 | 系列为空、全零或全 null |
| L7 | 热力图超过 200 个单元格 |
| L8 | 表格行数接近当前 grid 高度容量 |
| L9 | KPI 超过 4 个（请求校验通常会更早拒绝） |
| L10 | 图表超过 6 个（请求校验通常会更早拒绝） |
| L11 | 图例条目超过 8 个 |
| L12 | dataset/editor.data 有重复列名 |
| L13 | 只有单一颜色（信息提示） |
| L14 | 金额/比例语义指标未声明 measureTypes |
| L15 | 散点图两个轴几乎没有数据跨度 |
| L16 | 热力图颜色范围过窄或从 0 起点误导 |
| L17 | 比例指标使用 sum 或 stackedBar |
| L18 | 可编辑文本为空或只有空格 |
| L19 | 报告使用了非默认图表主题（提示可回 default 或确认品牌需求） |
| L20 | 价格/强度量在忽略品类列的切片上取平均——混合均值追踪构成，不是价格水平 |
| L21 | 发散型指标（利润/情感/相关性…）数据跨中点但无条件格式——正负同色读不出方向 |
| L22 | 标题提及该图未编码的真实列名（dimension/breakdown/measures 之外）——疑似漏声明 breakdown/breakdowns 或标题过度承诺（offer 看板「各国各品牌明细」vs 仅国家一类症状，2026-10-15） |

普通 lint 返回 0 并输出建议；`--strict` 有 warning 时返回 2。CI/交付顺序：先 validate，再 lint，最后在有 Node/Chrome 的环境运行浏览器审计。
